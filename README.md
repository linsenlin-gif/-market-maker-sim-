# 做市商模拟器

一个单文件网页小游戏：你扮演期权做市商，接客户订单、用股票和期权对冲，实时看到风险和盈亏。
目的是亲手体会 Delta 对冲、Gamma 对冲、做空/做多 Gamma、Theta 损耗，以及对冲行为如何影响股价（钉住 pinning 与 Gamma squeeze）。

界面为简体中文，手机竖屏可用，支持深色/浅色模式。

## 怎么打开

- 下载 `market-maker-sim.html`，用浏览器直接打开即可。无需联网、无需安装。
- `index.html` 与它内容相同，方便开启 GitHub Pages 后直接在线玩。

## 五个关卡

1. **只对冲 Delta**：客户持续买 Call，只能用股票对冲，观察“涨了买、跌了卖”的高买低卖。
2. **用期权对冲 Gamma**：按“需要张数 = Gamma 股数 ÷（该期权 Gamma × 100）”买入期权抵掉 Gamma，再用股票调回 Delta。
3. **做空 vs 做多 Gamma**：切换客户偏向，对比自动对冲的买卖方向，以及 Gamma 盈亏和 Theta 盈亏。
4. **到期前最后一小时**：Gamma 随时间暴涨，同样 1 块的波动要对冲的股数大得多。
5. **你的对冲会影响股价**：代表全体做市商，做多 Gamma 时价格被钉在 767 附近，做空 Gamma 时越走越远。

## 模型

- 一只模拟股票 `SPY`，起始价 767.00；行权价 762 / 765 / 767 / 770 / 772，Call 和 Put，同一到期日，合约乘数 100。
- Black-Scholes 定价（r = q = 0），隐含波动率默认 15%；每步 = 1 分钟，T = 剩余分钟 / (252 × 390)。
- 盈亏拆分：报价差收入、对冲成本、Gamma 盈亏（每步 0.5 × Γ × ΔS²）、Theta 盈亏、方向盈亏、其他（高阶误差）。

## 自检

页面底部“自检”区和浏览器 console 会显示：put-call parity、Call/Put Gamma 相同、Call Delta − Put Delta = 1、
有限差分检查 Delta / Gamma / Theta、“卖出 100 张 767 Call（Delta 0.50）显示相当于做空 5,000 股”的场景检查、
“假如股价 +1”预览与实际一致，以及盈亏拆分各项之和等于总盈亏。

纯教学模拟，不构成任何投资建议。
