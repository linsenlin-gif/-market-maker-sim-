# 做市商模拟器

一个单文件网页小游戏：你扮演期权做市商，接客户订单、用股票和期权对冲，实时看到风险和盈亏；再换个角度，看全体做市商的 Gamma（GEX）怎样影响股价。

界面为简体中文，iPad、电脑浏览器、手机都能玩，每种屏幕都是一屏装下、不用上下滑，支持深色/浅色模式。

## 怎么打开

- 下载 `market-maker-sim.html`，用浏览器直接打开。不联网、不用安装。
- `index.html` 与它内容完全相同，开启 GitHub Pages 后可以直接在线玩。

## 界面

整个页面一屏装下，只有交易记录、长说明这类区域在自己的框里滚动。

- **顶部条**：股价、剩余时间、当前关卡（点它换关、重开、看说明，菜单里也有 GEX 实验室）、“关卡 / GEX 实验室”页签（竖屏时并入关卡菜单，保证一行放下），右侧是 ▶/⏸、单步、速度（慢动作 / 1x / 2x / 5x）、自动/手动、设置、交易记录。
- **价格舞台**：股价走势和行权价横线（767 加粗）。切到“手动”后，按住右端的圆点上下拖就能拨动股价，角落有 −1 / −0.25 / +0.25 / +1。第 5 关起，价格点旁的小箭头表示这一步对冲把价格推动了多少；第 7–9 关右侧叠加每个行权价的 GEX 横条（Call Wall、Put Wall 标出数值）和 Gamma Flip 虚线，背景按总 GEX 正负分成淡蓝 / 淡橙两块，跨过翻转点颜色随之切换。
- **涨跌效果仪表**（核心）：指针 = 整体涨跌效果相当于多少股（Delta）。两根幽灵指针（涨的颜色 / 跌的颜色）= 股价上涨、下跌后指针会跑到哪，主指针到它们各有一条箭头，旁边直接写“股价 +1 → 指针往左跑 293 股”，这就是 Gamma。Gamma 太小、幽灵指针贴着主指针时，自动改成“股价 ±3 后”（或更大的整数）来显示，并注明“Gamma 较小，放大到 ±3 元显示”。股价每动一次，主指针留下一道淡出的轨迹，下面写“股价 +0.42 → 指针自己跑了 −123 股（这就是 Gamma × 股价变动）”。沙漏 = 每分钟时间损耗（Theta）。下面是“调回 0”按钮和可拖动的数量条（往右拖买股票、往左拖卖股票，松手后确认）。每笔对冲在指针旁弹出成交气泡，高买低卖会变色。
- **期权棋盘**：行 = 行权价，列 = Call | Put，黑线是当前股价（只画在两行之间的缝里，价签在最左边的行权价列）。第 1–5 关的 5 行按可用高度排满、不用滚动；第 7–9 关显示所有放得下的行权价，放不下时上下有“还有 N 个行权价”的按钮。持仓是筹码（买 / 卖 + 张数），格子越深表示这一格持仓的 Gamma 越大。点一格看每张的涨跌效果和 Gamma，向其他做市商买卖；第 2 关起直接给出“抵掉当前 Gamma 需要买入约 N 张”，一键按建议数量买入。持仓明细表放在“查看明细”抽屉里。
- **盈亏条**：第 1–4 关上方有“Gamma 对 Theta”拔河条：左边是高买低卖亏掉的（或低买高卖赚到的），右边是时间损耗赚到的（或付出的），一眼看出谁大。下面是瀑布图，报价差收入、对冲成本、Gamma、Theta、方向、其他依次累加到总盈亏；“隐藏方向”开关可以去掉没对冲时特别大的方向那一段。点任意一段看解释。第 3、5 关可以打开两种客户偏向的对比。
- **客户订单收件箱**：订单卡片带倒计时，按“接单 / 拒绝”或左右滑；接单后卡片飞向棋盘变成筹码。
- 每个组件右上角的 **?** 是这一块的大白话说明。

**慢动作**：速度里选“慢动作”后，每一步拆成三拍，每拍约 0.7 秒：① 股价动 → ② 仪表指针自己跑（这就是 Gamma）→ ③ 被迫对冲，指针回到 0（第 5、7–9 关还会显示这笔对冲把股价推了多少）。舞台上方会一拍一拍写出来。慢动作里第 ③ 拍总会自动调回 0，用来演示这条因果链。

颜色约定：红 / 绿只表示你自己的买卖和涨跌；GEX 场景（第 6–9 关、实验室）里，蓝 = 做市商做多 Gamma，橙 = 做空 Gamma。

手机竖屏：价格舞台和仪表常驻，棋盘、盈亏、订单、记录放在底部页签。

电脑浏览器：窗口较宽时（宽度 ≥ 1200 且宽高比 ≥ 3:2，例如笔记本上 1366×657 的浏览器窗口）改为三栏：左边价格舞台 + 棋盘，中间仪表 + 盈亏条，右边订单，矮窗口也不用滚动；大屏幕上字号自动放大。用鼠标时可以在价格舞台上滚动滚轮拨动股价（手动模式），可拖动的地方鼠标指针会变形，按钮有悬停反馈。

键盘快捷键：空格 开始/暂停 · → 单步 · 1 / 2 / 5 速度（0 慢动作）· M 自动/手动 · ↑ ↓ 手动拨股价 ±0.25（Shift 为 ±1）· Z 调回 0 · A / X 接单 / 拒绝 · L 交易记录 · Esc 关闭弹窗。

## 关卡

1. **只对冲 Delta**：客户持续买 Call，只能用股票对冲，体会“涨了买、跌了卖”的高买低卖。
2. **用期权对冲 Gamma**：在棋盘上向其他做市商买期权抵掉 Gamma，再把 Delta 调回 0；看 Theta 收入变少、多了对冲成本。
3. **做空 vs 做多 Gamma**：切换客户偏向，对比自动对冲的买卖方向和 Gamma / Theta 盈亏。
4. **到期前最后一小时**：Gamma 随时间暴涨（舞台左下角有小图），同样 1 块的波动要对冲的股数大得多。
5. **你的对冲会影响股价**：代表全体做市商；做多 Gamma 时价格被钉在 767 附近，做空 Gamma 时越走越远（Gamma squeeze）。
6. **读懂 GEX 图**：实验室的只读版，回答四道题：点出 Call Wall、点出 Put Wall、股价涨 1 块全体做市商要买还是卖多少股、拖动股价找出 Gamma Flip。答案在答题前不显示，提示要点“提示”才出现，答完给出推理。
7. **墙的测试**：价格由“随机冲击 + 冲击系数 × 全体做市商本步对冲净买入”推动。看 Call Wall 附近被压回、Put Wall 附近来回拉扯；可调“买保险的人在 Put Wall 附近兑现的比例”，兑现时做市商买回对冲股票，交易记录里写清原因。
8. **Gamma Flip**：开局在翻转点上方，价格缓慢下漂；顶部徽章显示在哪一边，读数里显示最近 30 步平均每步波动，跨过翻转点后波动明显变大。
9. **假设错了怎么办**：同一个分布，切换“机构卖 Call”和“散户狂买 Call”两种站位；前者价格在 772 下被压住，后者碰到 772 反而加速上冲。还可以打开“看不到的盘中仓位”，对比“你看到的 GEX”和真实结果。

## GEX 实验室

和“关卡”并列的沙盒，不计分。

- 上下两张图共用横轴（股价）。上图“现在这一刻，每个行权价的 GEX”：每个行权价两根柱子，实心是 Call、斜纹是 Put，蓝色朝上 = 做市商做多 Gamma，橙色朝下 = 做空 Gamma；Call Wall、Put Wall 用旗子标出。下图“假如股价走到这里，总 GEX 会是多少”：0 线加粗，曲线穿过 0 的地方标出 Gamma Flip，曲线上的圆点是现在的总 GEX。
- **拖竖线**改股价（两张图同步），**拖柱子**改那一格的未平仓张数，**点柱子**切换那一格做市商是买方还是卖方。
- 剩余时间、隐含波动率滑块；站位假设；四种预设（正常大盘、散户狂买 Call、Put 堆积、0DTE 集中在一个行权价）；“看不到的盘中仓位”开关会同时画出“GEX 显示的”和“真实的”两条曲线。

### 计算口径

- 单格 GEX（股/每 1 元）= 符号 × Gamma × 100 × 未平仓张数；符号默认 Call 记 +（做市商买入）、Put 记 −（做市商卖出），“散户狂买 Call”时 Call 也记 −，也可以逐格指定。
- 美元口径（次要）：股价每动 1% 要买卖的金额 = GEX × S × 0.01 × S。
- Call Wall = Call 一侧 GEX 绝对值最大的行权价（若那里做市商其实做空 Gamma，会标注“不是天花板”）；Put Wall = Put 一侧 GEX 绝对值最大的行权价。
- Gamma Flip：在当前价 ±5% 内以 0.1 元为步长重算总 GEX，取离当前价最近的正负翻转点（线性插值）。

## 导入真实数据（CSV）

在实验室里点“导入数据（CSV）”，可以粘贴文本或选择文件。表头大小写不敏感，列顺序不限：

```
# underlying=767.25, asof=2026-09-28T15:07-04:00
expiration,strike,type,open_interest,iv
2026-10-02,765,C,52340,0.142
2026-10-02,765,P,61210,0.151
```

- `type` 接受 `C/P` 或 `call/put`；`iv` 可选，缺失时按设置里的波动率计算并提示。
- 标的现价、计算时刻可以写在首行注释里，也可以在导入窗口里填。到期按当日 16:00 美东；剩余时间只算交易时段（周一到周五 9:30–16:00），不扣节假日。
- 多个到期日时可以选“全部合计”或单个到期日。
- 出错的行会逐行提示原因（第几行、哪一列、实际写了什么），可以选择忽略出错的行导入其余部分。
- 未平仓数据通常是上一交易日收盘后的统计，做市商站位是假设。

## 模型

- 一只模拟股票 `SPY`，起始价 767.00；关卡 1–5 的行权价 762 / 765 / 767 / 770 / 772，合约乘数 100。
- Black-Scholes 定价（r = q = 0），隐含波动率默认 15%；每步 = 1 分钟，T = 剩余分钟 / (252 × 390)。
- 第 5、7–9 关的价格冲击：自动对冲时，本步对冲的买卖和它推动的股价同时成交（解出两者一致的价格），每步冲击最多 1 元。
- 第 7–9 关把“市场未平仓 × 站位假设”换成全体做市商的账本，Delta、Gamma 和价格冲击都沿用同一套计算。

## 自检

“设置”抽屉底部和浏览器 console 会显示 19 项自检：put-call parity、Call/Put Gamma 相同、Call Delta − Put Delta = 1、有限差分检查 Delta / Gamma / Theta、“卖出 100 张 767 Call（Delta 0.50）显示相当于做空 5,000 股”、幽灵指针的预测与股价 +1 后实际一致、盈亏各段之和等于总盈亏、单格 GEX（Gamma 0.05、未平仓 80,000、做市商买方 → +400,000）、同一行权价净 GEX（+300,000）、构造分布的 Gamma Flip 落在中间且站位反转后总 GEX 整体反号、全体做市商账本的 Gamma 等于总 GEX、四个 CSV 解析用例，以及交易分钟数计算。
